## What changed, by item

**1 + 2 + 6 — analysis (`aqua_analyze.py analyze_mouse`, new modules):**
- `afferent2p/runbundle.py` — one dict per run on the recorded-frame grid (speed, still, running, pupil, excluded, kept-event onsets, CFU dF/F + per-CFU onsets; `cfu_ids` = AQuA2 CFU numbers after curation via `_cfu_for`'s new `orig_index`).
- `afferent2p/locotrials.py` (item 6, Yu's slides 5–12) — bouts (gap ≤ 1 frame bridged, ≥ 2 frames), trials: **strict** = 5 frames still → 15 frames running (≥ 80 %) → 10 frames still (≥ 80 %), **relaxed** = ≥ 5 still frames before a bout ≥ 2 frames; trials touching excluded frames dropped. Responses: population dF/F (mean of kept CFUs), event-count trace, per CFU; baseline = pre-window mean, peak = run-window max. Responsive rules side by side: `yu` (1+peak ≥ 1.5·(1+base), i.e. peak ≥ 0.5 + 1.5·base on dF/F — rarely met for afferents), `z` (peak − base ≥ 2 × robust SD of the population dF/F over still frames; **default in figures/acute-chronic**), `ev` (≥ 1 kept event in the run window). Per-CFU responsiveness: mean dF/F run − pre (and event probability) vs 500 circular shifts of the onsets, p < 0.05. Rest-only activity: still frames ≥ 10 frames (20 s) from any running. GLMs: Gaussian ridge, lagged standardised predictors, penalty by K-fold CV inside each random 75/25 split, held-out deviance explained averaged; Loco2Fluor = speed lags −5…10 s on trial frames (50 splits, 5 folds), LocoPupil2Fluor = speed + pupil(0–1) lags −20…20 s whole trace (20 splits, 10 folds), LOPO relative value clipped 0–1, kernels/peak coefficients per SD of the predictor; units = population + CFUs with ≥ 3 events. Behaviour check (% running, bouts, bout duration, speed, trials, pupil dilation). Outputs `loco_trials_<exp>.csv`, `loco_cfu_<exp>.csv`, `loco_glm_<exp>.csv`, `loco_glm_kernels_<exp>.csv`, `loco_summary.csv` (per run), `loco_conditions.csv` (per condition), `<exp>_loco.png` (3×4 panels), `<exp>_loco_cfu.png` (H4 peri-onset heatmap).
- `afferent2p/general.py` (item 1) — G1 `session_figures` (optostim: `<mouse>_session_<day>.png`, both FOVs on the real clock via `timecourse.run_clock`, stimulation gap hatched; Treg: `<exp>_session.png`, one block per day, clock estimated), G2 `state_rows` + `state_figure` (`<exp>_state.png`: rates / max dF/F running vs resting with run dots, % running, event boxes split by state on the mean image), G3 `ecdf_figure` (`<exp>_ecdf.png`, dF/F ÷ FOV 99th pct), G6 `pupil_rows` (`pupil_measures.csv`: 0–1 per FOV-day (1st–99th pct over the day's runs), variation, resting pupil (valid ≥ 10 % rest), loco dilation per trial, spontaneous dilations at rest via find_peaks prominence 0.1), G8 `acute_chronic` (`acute_chronic.csv`, `<mouse>_acute_chronic.png`: 17 measures, acute = cond/base (optostim), chronic = base(day)/base(day 1) per FOV, log axis clipped 0.05–20).
- `afferent2p/heatmaps.py` (item 2) — H1 `identity_traces`: rows = `match_cfus` identities, footprint of the home run carried into every run (home → run 1 → run via apply_transform, −angle/−shift inverse, dilated 1 px) + AQuA2 crop offset (`report._crop_offset`), one pass per movie (`_movie_traces`), dF/F F0 = 20th pct, excluded frames NaN, 0–1 per CFU; fallback without readable movies = AQuA2 `cfu["dff"]` where detected; `kmeans_order` (scipy kmeans2 k=3 on per-condition means, groups by last−base change); `updown` (20-s = 10-frame bin means, Mann–Whitney p < 0.05); outputs `<exp>_heatmap.png` (heatmap + onset raster + speed), `<exp>_updown.png` (pies + per-CFU rate scatter), `cfu_updown_<exp>.csv`, `cfu_traces_<exp>.npz`, `heatmap_summary.csv`. H3 = existing `<exp>_maps.png` shown in the heatmap section.
- `analyze_mouse` new args `loco, loco_glm, heatmaps, movies` (CLI `--no-loco --no-glm --no-heatmaps --no-movies`); `cfu_of()` cache; the v32 block runs after the maps block per experiment; session figures + acute/chronic after the loop. Runtime: 2608-1 (24 runs, no movies) 3 min incl. GLMs.
