## Findings
1. **No noise false alarms anywhere.** Null-movie events on the fibres are 0 at almost every setting and day (max 0.26/min in one cell with 2 real events); even thrARScl 1.5 is not fooled by pixel noise. The false-alarm rule never binds, so the choice is driven by recall → the lowest threshold in the grid wins. The grid should go lower to find the noise floor.
2. **Sensitivity floor.** At the current thr 2, the brightest injected class (nominal 0.4 dF/F) is recovered 0–46 % (260921_002: 46 %, 260911_001: 4 %, 260917: 21–33 %), the 0.1/0.2 classes ~0 %. At thr 1.5: 0.4 class 29–85 %, 0.2 class 0–21 %, 0.1 ≤ 9 %. Units: AQuA2 grows the footprint 2–3× (80 px injected → 220–270 px detected, 400 → 940) and extends the duration (30-frame kernel → 54 frames), and reports the footprint-average dF/F, so a nominal 0.4 injection is reported at 0.14–0.34 (mostly ~0.2). The real events AQuA2 detects at thr 2 are reported at 0.3–0.46 dF/F, 140–1100 px, 8–19 frames (two multi-minute plateaus of 0.07/0.2) → they correspond to nominal ~0.6–0.9: the injected set probed mostly BELOW the current detection floor; overall recall (0.0–0.3) understates how real-sized events are caught. Per class (r0.4) is the number to read.
3. **What thr 1.5 adds in reality (260921_002, figure `tune_260921_002_events_on_off_fibre.png` sent to the user):** 11 → 46 events; 23 of the 35 new ones are off the fibre mask and nearly all new ones (on and off) cluster around the vessel crossing at raw (y 280–420, x 450–570): large (400–4200 px), long (16–74 frames), dim (0.08–0.3 dF/F) events, 9 of them starting at frames 388–415 (a burst) — coherent signals (absent from the null), most likely vessel-related brightness changes (hemodynamic / pulsation / wall), not afferent transients. (a) Check the 260921_002 hotspot and the vessel-region events in cfu_curate (Step-4 result) — if the hotspot is the vessel wall, the max-power FOV2 "effect" in the report is partly vascular. (b) Second, focused sweep in the realistic range: `--grid thrARScl=1.25,1.5,1.75,2 --grid maxSize=inf,1500 --grid minSize=50 --amplitudes 0.3,0.6,1.0 --sizes 200,400,800 --workers 2` (6 movies × 9 settings × 3 = 162 jobs ≈ 2 h with 2 processes). maxSize is honoured in `act/acDetect.m` (`curSz > maxSize` → region dropped) and a finite maxSize switches AQuA2 to its multi-threshold active-region mode (thresholds thrARScl → maxdF in 10 steps), which can split large regions — so it is a real algorithm change, not only a cap.
