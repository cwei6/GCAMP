# aqua_tune v37 — why the Oct 21 sweeps chose blind settings, and what changed (Oct 23, 2026)

Trigger: the user hand-tuned NavRearChrTIGRE-2609-1_261014_008 (FOV 2, last post run of the "5 Hz max power + 40 ms" day) in the AQuA2 GUI — thrARScl 2, minSize 20, otherwise the pipeline's values — and got 144 events (9.2/min; area p10–p90 29–194 px, median 42 px; max dF/F 0.18–0.41, median 0.29; duration ~6 frames) on the afferents, while the auto-tuned setting (matched rule: pre thr 1.5/minSize 100, post thr 2/minSize 50) found 0 events in 008 and 4 in 006. Files: `<run>\<run>_bin31f_1p98s\<...>_AQuA2.mat` (hand result, 1.5 GB), `<run>\<run>_bin31f_1p98s_Opt.csv` (hand Opt).

## Three causes, found from the sweep tables on samson

1. **The injected transients probed below the real signal — on EVERY animal swept on Oct 21.** The v30–v36 default classes were nominal 0.1 / 0.2 / 0.4 dF/F × 80 / 200 / 400 px. AQuA2 grows the footprint 2–3× and reports the footprint-average dF/F, so these are reported at ~0.05–0.2 — dimmer than nearly every real event (real: 0.2–0.45). Result: recall ≤ 0.3 at every setting of every movie of 2609-1 AND 2608-1 (the 0.1 / 0.2 classes ~0 everywhere; the 0.4 class 0.2–0.7 only at thr 1.5), so the "most sensitive clean setting" was chosen among blind settings (2608-1 260921_006: "thrARScl=4 minSize=50, recall 0.00" chosen; the matched rule "matched" pre and post at levels of 0.00–0.2). The Oct 10 second sweep (the one that gave recall 0.82 at thr 2 — `claude/aqua-tune-first-real-sweep-results.md` advised it) used 0.3 / 0.6 / 1.0 × 200 / 400 / 800, but the defaults were never changed, and the overnight sweeps of Oct 21 ran with the GUI's default fields.
2. **The grid stopped at minSize 50** while this field's events are 20–50 px (minSize is applied to the active region before growth): the hand setting minSize 20 was outside every grid.
3. **The automatic fibre mask dropped the whole fibre network on 2609-1 FOV 2**: `_elongated_only` kept only connected pieces ≥ 2.5× longer than wide; a dense network of crossing fibres is ONE big connected piece as wide as it is long → dropped as a "round speck"; only isolated short bits survived. So the transients were injected on specks, and real fibre events counted as "off the fibres" (the on-fibre ≥ 80 % rule then preferred settings with 0–4 events). 2608-1's masks (sparser, parallel fibres) were fine.

## v37 (delivered Oct 23: working copy, `afferent2p_v37\`, zip)

- Defaults: amplitudes **0.3 / 0.6 / 1.0** (reported ≈ 0.15 / 0.3 / 0.5: below / at / above the real events), sizes **20 / 60 / 200 px**, grid thrARScl **1.5 / 2 / 2.5** × minSize **20 / 50 / 100** (3 and 4 never chosen on any animal). The plan replaces the OLD default classes by the new ones when given (the GUI fields are not persisted, so they now show the new defaults); a non-default class list is used as given; an existing plan keeps its own classes unless given.
- `_elongated_only`: a piece is kept when its skeleton is ≥ 10 µm long (networks pass) or elongated as before; `MASK_VERSION = 2` recorded in `fibre_mask_raw.json`; an older saved mask is recomputed by the next plan (→ injected movie remade, inject results moved aside); the frame's 6-px border is never a fibre; injection sites go on pieces with skeleton ≥ 25 px (`long_pieces`).
- **Grid verdict** per movie in the report (`T.grid_verdict`): *too strict* (best clean setting at the permissive edge of some swept variable and recall < 0.5), *edge* (recall 0.5–0.7 at the edge), *too permissive* (nothing clean), *weak*, *ok*; one-step suggestions (`_step_beyond`: thrARScl −0.25 below 2 / −0.5 above, floor 1.0; minSize ÷ 2.5 rounded to 5, floor 10; generic ×0.8) written to `aqua_tune\grid_suggestion.json` (deleted when all ok). `aqua_tune.py --plan --extend` merges them (`merge_grid`, `read_grid_suggestion`); GUI tab 3 *Extend the grid (as suggested)*; *Run all* does one extension round by itself (plan → sweep → report+apply). `pipeline_state` says "grid too narrow for k movie(s)".
- **Re-plan by VALUES**: on a grid change, `sNN` folders are matched to the new settings by their values (from `settings.json`), renumbered (two-step rename) and kept; only folders whose values left the grid go to `stale_<date>\`. A regenerated injected movie whose truth table differs from the earlier one moves the old inject results aside.
- **Classes check**: `score_setting` records the reported dF/F of the matched injected transients (`inj_dff_reported[_amp…]`, via `match_truth(..., return_index=True)`); the report compares the brightest class with the real signal (the hand result's events when present, else the chosen setting's own events when ≥ 10) → "the injected classes probe BELOW the real signal … plan again with --amplitudes a,b,c"; `result["amplitudes_suggest"]`.
- **Mask check**: "the fibre mask may be incomplete" when ≥ 50 % of the events at the chosen setting lie off it; "this setting finds NO event".
- **Matched rule floor** `--min-recall 0.30` (`recommend_matched(min_level=…)` → `info["weak"]`, not passed → NOT COMPARABLE, common setting written).
- **Hand result as the reference**: `aqua_export_events.m` (standalone MATLAB; same export as the CFU batch) writes `_events.csv/_eventmap.tif/_meanimg.tif` next to any `_AQuA2.mat`; `find_reference(tif)` looks in `<run folder>\<stem>\` (AQuA2 GUI save folder) or `<stem>_reference_events.csv`; `T.score_reference` → `ref_recall` (hand%), `ref_extra` (extra%), `ref_n`; report columns, "closest to the hand result: setting k", flag when the chosen setting recovers < 50 %; white dashed circles in the why figures (`_why_panel(reference=…)`); a hand result on a run not in the plan is listed ("add it with runs: …"); an un-exported .mat is listed with the MATLAB command. GUI tab 3 *Hand result → reference (MATLAB command)*.
- GUI: title v37; tab-3 third button row; Run-all extension round + classes note.
- Tests: `grid_verdict`/`recommend_matched` on the real 2609-1 and 2608-1 tune_report tables (all movies too strict/weak; matched TOO WEAK on every day); plantest2 bed (fake movies): same-grid re-plan, changed grid (renumbering: s03→s02, 6 stale, old classes → new, inject remade), `--plan --extend` with a suggestion file (9 settings, 4 jobs kept), `pipeline_status`; tunetest4 report+apply with a fake hand result (hand% / extra% columns, closest setting); GUI tab-3 screenshot, Stop test.
